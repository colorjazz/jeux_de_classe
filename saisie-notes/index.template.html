Saisie de notes automatique

Un favori qui lit votre feuille de notes (photo ou PDF, même manuscrite) et inscrit les notes de vos élèves dans le site de notes (Mozaïk ou autre), au bon endroit.

0. Obtenir une clé API Claude (une seule fois)

La lecture des photos utilise Claude via une clé API. Elle se paie à part de l'abonnement Claude : environ 2 à 7 sous par feuille.

  1. Créez un compte sur console.anthropic.com.
  2. Dans Billing, ajoutez un petit montant de crédits (par exemple 5 $).
  3. Dans Limits, fixez une limite de dépenses mensuelle basse, par sécurité.
  4. Dans API Keys, cliquez sur Create Key et copiez la clé (elle commence par sk-ant-).

Gardez cette clé pour vous : quiconque l'a peut utiliser vos crédits. Sans clé, le favori fonctionne quand même, en collant la liste à la main.

Confidentialité : la photo (avec les noms des élèves) et la liste des noms du groupe sont envoyées à Anthropic pour être lues. Vérifiez que c'est permis par votre centre de services scolaire.

1. Installer le favori (une seule fois)

Affichez la barre de favoris (Ctrl+Maj+B), puis glissez ce bouton dans la barre :

📝 Saisie notes

Le glisser-déposer ne fonctionne pas ?

Copiez le code ci-dessous, faites un clic droit sur la barre de favoris → Ajouter un favori / une page, nommez-le « Saisie notes » et collez le code dans le champ Adresse (URL).

La clé est enregistrée dans le favori lui-même. Si vous changez de clé, supprimez l'ancien favori et refaites cette étape.

2. Remplir Mozaïk

  1. Ouvrez la page de saisie des notes de l'évaluation.
  2. S'il y a plusieurs évaluations (colonnes) sur la page, cliquez dans une case de la bonne colonne.
  3. Cliquez sur le favori 📝 Saisie notes : un panneau s'ouvre à droite.
  4. Cliquez sur 📷 Lire une photo ou un PDF et choisissez le fichier (plusieurs pages possibles). Claude lit la feuille en s'aidant des noms affichés dans Mozaïk, et la liste apparaît dans le panneau. Vous pouvez aussi coller une liste Nom ; note vous-même.
  5. Comparez la liste avec la feuille, surtout les cas « À vérifier ». Corrigez au besoin directement dans la liste.
  6. 1. Vérifier : chaque élève est repéré et sa case est entourée.
    • Vert : trouvé.
    • Jaune (≈) : nom approchant (faute de frappe, nom incomplet), à vérifier.
    • Orange : case déjà remplie (non remplacée, sauf si vous cochez l'option).
    • Rouge : élève introuvable, ambigu, ou note illisible (??) : à saisir à la main.
  7. 2. Remplir : les notes sont inscrites. Les cases restées vides dans la colonne sont entourées en orange.
  8. Vérifiez, puis cliquez sur Enregistrer dans Mozaïk. Le favori n'enregistre jamais à votre place.

Secours : lire la photo ici

Si le favori affiche « Connexion à Claude impossible », Mozaïk bloque peut-être la connexion. Lisez alors la feuille ici (avec la clé collée plus haut), copiez la liste et collez-la dans le panneau du favori.

Sans la lecture de photo, tout se passe dans votre navigateur. Avec, seuls la feuille et les noms du groupe sont envoyés à Claude ; les notes ne sont écrites dans Mozaïk que par votre navigateur.
