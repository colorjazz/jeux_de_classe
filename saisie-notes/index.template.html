Saisie de notes automatique

Un favori qui inscrit les notes de vos élèves dans le site de notes (Mozaïk ou autre), au bon endroit, à partir d'une liste Nom ; note.

1. Installer le favori (une seule fois)

Affichez la barre de favoris (Ctrl+Maj+B), puis glissez ce bouton dans la barre :

📝 Saisie notes

Le glisser-déposer ne fonctionne pas ?

Copiez le code ci-dessous, faites un clic droit sur la barre de favoris → Ajouter un favori / une page, nommez-le « Saisie notes » et collez le code dans le champ Adresse (URL).

2. Transformer le PDF en liste

Peu importe la forme du PDF (tableau, feuille manuscrite, photo), il faut obtenir une liste comme :

Tremblay, Léa ; 25
Gagnon Samuel ; 43,5
Roy Emma ; abs
  • PDF avec du texte : un copier-coller suffit souvent.
  • PDF manuscrit ou scanné : déposez-le dans Claude avec la demande ci-dessous. Pour éviter les erreurs de lecture des noms, collez aussi la liste de votre groupe (copiée depuis Mozaïk).
Lis ce document et donne-moi les notes de chaque élève, une ligne par élève, au format exact :
Nom Prénom ; note

Règles :
- Ne mets rien d'autre que la liste (pas de titre, pas de commentaire), dans un bloc de code.
- Utilise l'orthographe des noms de la liste de mon groupe ci-dessous quand c'est le même élève.
- Si une note est illisible ou douteuse, écris ?? à la place de la note et ajoute après la liste les cas à vérifier.
- Absent : écris « abs ».

Liste de mon groupe :
(collez ici les noms copiés depuis Mozaïk)

Relisez toujours la liste : une note manuscrite mal lue reste possible. Les lignes avec ?? sont ignorées par le favori et signalées en rouge.

3. Remplir Mozaïk

  1. Ouvrez la page de saisie des notes de l'évaluation.
  2. S'il y a plusieurs évaluations (colonnes) sur la page, cliquez dans une case de la bonne colonne.
  3. Cliquez sur le favori 📝 Saisie notes : un panneau s'ouvre à droite.
  4. Collez la liste, puis 1. Vérifier : chaque élève est repéré et sa case est entourée.
    • Vert : trouvé.
    • Jaune (≈) : nom approchant (faute de frappe, nom incomplet), à vérifier.
    • Orange : case déjà remplie (non remplacée, sauf si vous cochez l'option).
    • Rouge : élève introuvable ou ambigu, à saisir à la main.
  5. 2. Remplir : les notes sont inscrites. Les cases restées vides dans la colonne sont entourées en orange.
  6. Vérifiez, puis cliquez sur Enregistrer dans Mozaïk. Le favori n'enregistre jamais à votre place.

Tout se passe dans votre navigateur : aucune donnée n'est envoyée ailleurs.
