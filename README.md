# Jeux merdiques de Mr. Plante

Page d'accueil style arcade qui regroupe les jeux de classe de Mr. Plante.

Le site est un simple fichier statique : `index.html`.

## Mettre le site en ligne (GitHub Pages)

1. Sur GitHub, ouvrir **Settings → Pages**.
2. Sous **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche `main` et le dossier `/ (root)`, puis **Save**.
4. Après une minute environ, le site est accessible à :
   `https://colorjazz.github.io/jeux_de_classe/`
